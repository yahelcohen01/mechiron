## 4. Environment gotchas

- **Claude's Bash tool has no outbound network.** A dev server started from it cannot reach Supabase —
  every request fails `fetch failed` in the auth middleware. The user runs
  `! LOG_LEVEL=debug npm run dev` themselves. (`gh` does work.)
- **Node resolves imports from the script's own directory.** A throwaway script in `/tmp` cannot
  `import { generateText } from 'ai'` — put it in the repo root and delete it after.
- **The Chrome extension needs localhost permission**, or `navigate` bounces to `chrome://newtab/`
  with no error.
- **`/rfq` is not a route.** The dashboard is `/`; detail pages are `/rfq/{uuid}`.
- **Collapsed domain sections are not in the DOM.** "Element not found" means collapsed, not absent.

## 6. Lessons this epic has paid for — do not relearn them

- **Typechecks and green tests are not a working feature.** #13 shipped with 112 passing tests and a
  UI that had never executed. #35 was found only because someone clicked a checkbox.
- **One run of a non-deterministic lane proves nothing.** Two beliefs in this epic came from single
  runs and both were false: that reading was solved at the cheapest tier, and that the latency was
  the model's rather than a configuration default. Run the eval lane **twice**, always.
- **An applied migration is history.** Verify against `supabase migration list`, never a commit
  message.
- **A silently-failing write is worse than a loud one** — [decision 0001](../../decisions/0001-check-row-counts-not-just-errors.md).
- **A rule that must hold every time belongs in code, not the prompt.**
- **Check a ticket's premises before building it.** #16's body specified crops for six weeks after the
  decision that removed them; the correction was in a comment. #15's body is still wrong today.
- **Re-read before concluding.** A "the row is gone" conclusion was wrong once — the section had
  merely collapsed.
